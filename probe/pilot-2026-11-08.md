# Second pass, 2026-11-08

Eleven more clients from the structured-content research pins (opencode, Cline CLI, fast-agent, Hermes Agent, pi, eve, Strands, crewAI, deepagents, Google ADK, Agent Framework), plus the `_meta` scenarios on the six pilot clients. Each client's records are in `runs/<client>@<version>/` and collected in `../data/verified/<client>.json`; `../cards/tool-results.md` is the matrix. Verdicts use the clients page glyphs: `[…]` content, `{…}` structuredContent, `⟨…⟩` the whole envelope, `"…"` a placeholder or error text.

Adapters were written in parallel, one agent per client, against the research note for that client. Unless a row says otherwise, every default-config observation agreed with the note; the lists under each client are the additions and the disagreements.

## Shared fixes the pass forced

Four problems came up in more than one adapter and were fixed in the shared code after the reports came in, then every record was recomputed with `scripts/reclassify.ts`.

- The mock routed on the raw URL, so the Anthropic SDK's `POST /v1/messages?beta=true` got a 404 (pi, fast-agent, Agent Framework). `apiFor` now matches on the path.
- The classifier set `toolOffered` only from tool names in the request, so a fixture tool reached through a script or bridge tool (pi `codemode`, opencode `execute`, eve `eve__tool`, deepagents `js_eval`) or under a hashed name (crewAI stdio) was reported as "tool not offered" although the result reached the model. A call whose arguments name the fixture tool, or whose call id starts with `call_probe_fixture`, now counts as the fixture tool reached indirectly, and its result is the one classified.
- An SDK validation error that quotes the rejected value carries `MARK_SC_91be`, so `schema_mismatch` and `sc_string` read as `{…} structuredContent only` (strands, crewAI, ADK, fast-agent, hermes, opencode). On the five fixtures the SDK may reject, a payload that starts with a client error prefix is now recorded with `clientError: true` and the verdict `"…" client error text`.
- `findFinalText` kept a trailing carriage return from Python clients on Windows.

Also added: `HostAdapter.transports`, so eve's adapter declares `['http']` and the runner refuses stdio instead of writing failed records.

## Caveats carried forward

- The `large` verdicts depend on the client's assumed context window and size caps: fx without a store, crewAI with an unknown model, pi at 20 KB, Cline at 8,000 chars. A cell on the matrix should be read with its record.
- fast-agent's programmatic tool calling and the fx hosts run only on POSIX; those configs need a WSL run.
- Python start-up on this machine is slow when the venv sits under OneDrive. Runs that time out at the default 120 s succeed with `--timeout 300000` and after `python -m compileall` over site-packages.
- The research repo's pins moved for opencode, codex, goose and mastra on 2026-11-08 (research main `3e89f16`). See the next section for what that changed.
